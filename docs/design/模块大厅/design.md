# 模块大厅 · 设计意图

1. 打开 App 先见大厅，不再直接进选人。大厅以模块卡呈现：杠精陪练房（主推大卡）+ 话术资料库 + 好友擂台。后两者未落地前显示「即将开放」，可看不可点，不做死链。

2. 对线是主模块，体验优先级最高：大厅只能加分，不能伤对线。切去大厅再回来，进行中的对局必须原样还在（对话记录、怒气、轮次），倒计时可暂停但回大厅不许清局。

3. 选人屏、报告屏、对线屏头部都要有回大厅的路；对线中允许走（AI 回复照常记账，回来再补看）。

4. 顶栏（品牌/引擎徽章/皮肤/主题/设置/声音）不动，跨模块共用。

5. 视觉走现有令牌体系（四态皮肤自适应），不引入新色；本轮不加新图标，返回按钮用文字（图标预算留给 A2/A3）。
