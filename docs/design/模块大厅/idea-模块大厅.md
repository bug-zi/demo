# 模块大厅（应用外壳）

> 状态：已商定排期（260911 凌晨），待开发者说「立项」进 design/<模块>/
> 排期：9.11 上午（半天小活）｜来源：新功能.md「多模块扩展」分解件①

## 是什么

打开 App 先见「话术健身房」大厅：模块卡片入口——杠精陪练房（主推大卡，进行中对局带角标）、话术资料库、好友擂台。选卡进模块，模块内可返回大厅。

技术形态：`main.js` 状态机加一层 `module` 维度（`lobby / duel / library / arena`），lobby 成为新初始态；现有 `select → duel → report` 降为 duel 模块内子状态，对线玩法逻辑零改动。

## 为什么

- 多模块扩展的地基：资料库、好友擂台都要挂在入口结构上，晚做会与 A2/A3 的 UI 改动互相冲突。
- 评委一眼看到平台形态，服务「话术健身房」叙事（建成的房间才上大厅，符合「平台叙事只进文档不进 demo」纪律）。

## 最小版本

- lobby 态 + 三张模块卡（好友擂台未落地前显示「即将开放」态，不做成死链）
- 切走再切回**不销毁进行中对局**（与「对线中可开皮肤弹层」同一精神）
- 顶栏（主题/皮肤/声音/设置）跨模块共用不动

## 关键决策（已与开发者对齐）

- 入口形态选「模块首页大厅」而非顶栏常驻切换（平台感 + 默认叙事）。
- 降级预案：卡片可降级为简单列表（是否降级由开发者拍板），不阻塞后续模块。
