# 样式优化设计方案（双主题 + 背景图 + 图标体系）

> 状态：已归档——260910 随「样式优化（双主题+背景图+图标体系）」落地（smoke/dom-check 全绿）｜ 2026-09-10 ｜ 输入：样式规范（本模块 design.md）四条规则 + 浏览器 mockup 三轮选型
> 产出后由 writing-plans 拆实施计划；实施完成时本方案转正/归档，`project/视听与界面.md` 同步更新

## 1. 目标（来自 样式.md）

1. 浅色（樱花粉 `#E8A0BF` 主 + `#1F1F1F` 字）与深色（宝蓝 `#1A237E` 系 + 白字）双主题，切换即时生效
2. `bg-light.png` / `bg-dark.png` 铺满窗口，内容卡片半透明叠加，背景保持可见
3. 全 App 禁 emoji 图标，统一 Material Symbols Outlined 线性风格，自托管不依赖外网
4. 组件框/按键/弹窗禁止彩亮色，只用主题色系（游戏语义色是唯一豁免，见 §4）

## 2. 已定决策

| 决策点 | 结论 | 备选与否决理由 |
|---|---|---|
| 切换入口 | 顶栏图标按钮 + 设置弹窗「外观」分段控件 | 样式.md 的「侧边栏底部」属个人档 App，本项目无侧边栏 |
| 语义色 | C 方案：冷静段用主题色、上头/破防转暖红 | A 照搬现状（黄绿与主题打架、浅色下金黄对比度不足）；B 全主题渐变（丢失"越怒越红"直觉） |
| 人设头像 | Material Symbols 圆底：网友 `keyboard`、亲戚 `theater_comedy`（阴阳脸谱）、老板 `cake`（画饼） | B 保留 emoji（与线性图标语言割裂）；C 单字色块（表意弱） |
| 架构 | CSS 变量 + 内置 SVG 图标（CSS mask 渲染） | Material Symbols 字体连字（全量 4MB 过重；子集化需维护构建脚本 + 首帧闪烁） |

## 3. 主题机制

- `<html data-theme="light|dark">` 驱动；`styles.css` 重写为语义令牌制，颜色只经令牌引用
- 新增 `src/lib/theme.js`（约 40 行）：`initTheme()` / `toggleTheme()` / `applyTheme()` / `getTheme()`
  - 首次访问读 `prefers-color-scheme`；手动选择后存 `localStorage`（键 `gang-ai:theme`）
  - `applyTheme()` 设 `data-theme` 并同步顶栏按钮图标与 aria-label（浅色时显示 `dark_mode`，深色时 `light_mode`）
- 切换动效：全局颜色 0.2s transition；`prefers-reduced-motion` 下关闭
- `:focus-visible` 外描边用 `--accent-strong`（无障碍，两主题均可见）

## 4. 设计令牌

### 4.1 基础令牌（chrome，规则 4 管辖）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#E8A0BF` | `#283593` | 主按钮底、选中态 |
| `--accent-hover` | `#D98CB0` | `#3A499E` | 主按钮/卡片 hover |
| `--accent-soft` | `#F8BBD0` | `rgba(121,134,203,.28)` | 次级底、我方气泡 |
| `--accent-strong` | `#C25C8D` | `#9FA8DA` | 图标、强调文字、focus 描边 |
| `--text` | `#1F1F1F` | `#FFFFFF` | 正文 |
| `--muted` | `rgba(31,31,31,.62)` | `rgba(255,255,255,.64)` | 次要文字 |
| `--surface` | `rgba(255,252,253,.78)` | `rgba(15,25,62,.66)` | 卡片/顶栏/弹窗底 |
| `--surface-deep` | `rgba(255,255,255,.9)` | `rgba(10,18,48,.8)` | 输入框、嵌套层 |
| `--line` | `rgba(31,31,31,.1)` | `rgba(255,255,255,.16)` | 边线 |
| `--bg-img` | bg-light.webp | bg-dark.webp | body 背景 |

主按钮文字色：浅色 `#1F1F1F` / 深色 `#FFFFFF`（令牌 `--on-accent`）。

### 4.2 语义色阶（C 方案，规则 4 唯一豁免）

| 阶段/信号 | 浅色（脸涨红隐喻） | 深色（冷→热隐喻） |
|---|---|---|
| 礼貌 polite | `#F8BBD0` | `#9FA8DA` |
| 阴阳 sarcastic | `#E8A0BF` | `#5C6BC0` |
| 上头 agitated | `#E0608F` | `#FF8A80` |
| 破防 breakdown | `#C2185B` | `#FF5252` |
| 软肋命中 | `#C25C8D`（玫粉） | `#9FA8DA`（淡宝蓝） |
| 自爆 | `#AD1457` | `#FF8A80` |
| 胜 / 负 / 平 | 命中色 / 破防色 / muted | 同左 |

实现为 6 个语义令牌：`--stage-polite` / `--stage-sarcastic` / `--stage-agitated` / `--stage-breakdown` / `--hit-softspot` / `--hit-self-destruct`；怒气条 fill、stage-pill、quip/判定标签引用前四个，胜负徽章直接复用 softspot / breakdown 色，平局用 muted（不新增令牌）。

### 4.3 气泡区分

| | 对方 | 我方 |
|---|---|---|
| 浅色 | `rgba(248,187,208,.4)` 粉底 | `--surface-deep` 白底 |
| 深色 | `rgba(255,255,255,.08)` 中性 | `rgba(121,134,203,.28)` 淡宝蓝 |

## 5. 背景图

- 现图 PNG 共 4MB（1.8 + 2.2MB）→ 转 WebP（质量 ~82，目标各 ≤300KB）入 `src/assets/`
- `body` 铺 `center/cover`；App 不滚动（日志区内滚），无 iOS fixed 坑
- 顶栏/卡片/弹窗 `--surface` + `backdrop-filter: blur(8px)`；`@supports not (backdrop-filter: blur(1px))` 时把 surface 不透明度提到 ≥.92 兜底
- 验收：两主题 × 背景四角/中心取样，正文对比度 ≥ 4.5:1（bg-dark 四角有宝蓝光晕，是重点抽查位）

## 6. 图标系统

- 来源：npm 包 `@material-symbols/svg-400@0.47.2`（已验证可达），**拷贝所需 SVG 进仓库** `src/assets/icons/`，不装运行时依赖
- 必需清单（14 个，共约 10KB）：`settings` `volume_up` `volume_off` `light_mode` `dark_mode` `close` `star` `star_half` `star_outline`（若不存在则 `star`+opacity .3 兜底）`target` `bolt` `keyboard` `theater_comedy` `cake`
- 渲染：CSS mask + currentColor（主题/悬停变色全自动）：

```css
.icon { display: inline-block; width: 1.25em; height: 1.25em;
  background-color: currentColor;
  -webkit-mask: var(--icon) center / contain no-repeat;
  mask: var(--icon) center / contain no-repeat; }
.i-settings { --icon: url('../assets/icons/settings.svg'); }
```

- DOM 用法：`h('span', { class: 'icon i-settings', 'aria-hidden': 'true' })`，纯类名切换，不碰 innerHTML
- 头像：`.avatar`（主题色淡底圆）内嵌 `.icon`，`personas.js` 的 `avatar` 字段值改为图标名
- 判定标签：`fallbacks.js` 标签文本去 emoji（`🎯 扎心了`→`扎心了`），图标由 UI 层拼（`target`/`bolt`）
- 难度星：`star` × n + `star_outline` × (5-n)，替换 `main.js` 的 `★☆` 字符串
- 纯图标按钮保留/补 `aria-label`（主题按钮「切换深浅主题」）

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| bg-dark 边缘光晕压低白字对比度 | surface 不透明度/blur 可调档；验收不过则深色 surface 提到 .75 |
| `star_outline` 在图标包中不存在 | `star` + opacity .3 兜底（实施时确认） |
| 老 Safari 的 mask 前缀 | 同时写 `-webkit-mask`（§6 已含） |
| jsdom 不渲染 mask/blur | 仅视觉属性，断言不涉及；dom-check 照常跑 |

## 10. 不做（范围边界）

- 不改三屏布局结构、不加侧边栏/路由、不动引擎数值与对局规则
- 不引入运行时依赖（框架/字体/图标库零新增）
- 不给纯文字按钮（战报三按钮、弹窗按钮）强加图标
- 不做主题自动定时切换等花活
