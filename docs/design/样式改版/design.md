# 样式

1.要有浅色模式和深色模式两种。浅色主题为樱花粉+黑色字；深色主题为宝蓝+白色字。

参考色值（开发时可微调，保持色系不变）：

- 浅色主题：樱花粉主色 #E8A0BF（辅 #F8BBD0），文字 #1F1F1F，背景图 bg-light。
- 深色主题：宝蓝主色 #1A237E（辅 #283593），文字 #FFFFFF，背景图 bg-dark。

2.背景图片用我上传的 bg-light（浅色主题用）和 bg-dark（深色主题用）图片。应用方式：背景图铺满全窗口，内容卡片/列表使用半透明底色叠加其上，保持背景可见。主题切换即时生效（入口见个人档 design.md：侧边栏底部 + App 设置）。

3.样式禁止使用emoji图标，需要图标上网搜索 https://fonts.google.com/icons 获取，全 App 统一使用 Material Symbols 的 Outlined 线性风格。

4.组件框按键框弹窗等禁止使用彩亮颜色，要使用和主题色相近的色系，使得整体色彩风格保持一致。
