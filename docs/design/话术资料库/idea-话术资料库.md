# 话术资料库

> 状态：已立项（260911 01:14），实施中。意图见 `design.md`，实现规格见 `designs-specs.md`。
> 排期：由开发者自行协调｜来源：新功能.md「多模块扩展」分解件②（260911 凌晨商定）

## 是什么

本地话术查阅模块：内置回怼话术按场景分类浏览 + 关键词搜索 + 收藏星标 + 「我的」页签（收藏 + 自建笔记，localStorage 持久化）。将来广场/UGC（分享、审批、公开库）明确**本轮不做**，本地笔记库为 UGC 留种子。

技术形态：`src/data/comebacks.js`（内置话术）+ `src/lib/notes.js`（收藏/自建 CRUD，localStorage 键 `gang-ai:*`）+ `src/ui/library.js`（渲染）。

## 为什么

- 补「实用性」维度：对线练完有东西可带走，服务「娱乐为壳、训练为核」定位。
- 纯本地零网络，完全符合离线铁律；内容生产可由 AI 初稿 + 开发者人工筛并行。

## 最小版本

- 分类筛选 + 搜索 + 收藏 + 自建（增/删/改）三档全量即本轮目标。
- 内容源：`draft/260911-资料库话术初稿.md`（120 条）。

## 关键决策（已与开发者对齐）

- 功能档位：查阅 + 收藏 + 自建笔记（三档全做）。
- 内容生产：现有素材（人设/计划书）提炼打底 + AI 批量生成初稿（~120 条）+ 开发者人工筛。
- 话术字段 schema（场景/攻防类型/标签等）在 designs-specs 细定。
- 纯离线可用，走既有主题/皮肤令牌，不新增网络依赖。
