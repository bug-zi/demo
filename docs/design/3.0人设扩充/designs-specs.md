## 1. 交付单元规格（personas.js 条目逐字段要求）

| 字段 | 要求 |
|---|---|
| `id` | 英文小写 kebab，唯一；下表已定名，不得重复 |
| `name` / `category` / `difficulty` | category 按 roster 归房；difficulty 星按 roster（关卡排序依据） |
| `avatar` | Material Symbols 图标名（美术 A1 立绘到位前的头像降级）；`portrait` **不写**（字段留给美术轨，无 portrait 时回退图标渲染） |
| `tagline` / `catchphrases` | tagline 一句口头禅（选人卡展示）；catchphrases 2–3 个高频口头语 |
| `intro` / `opener` | intro 一两句场景白描；opener 开场白（情商房按 §2 语义写「怒气开局」） |
| `presets` | ≥3 条预设话术（玩家可点），覆盖进攻/迂回/试探三种打法 |
| `softspots` ×3 | 每条：`key`（英文 slug）、`label`（玩家视角动作短语）、`delta` 24–34 域、`keywords` ≥6 个中文变体（含口语/标点变体，只做包含匹配，勿写单字） |
| `stages` | `polite`/`sarcastic`/`agitated` 三键各 3 条台词（语义见 §2） |
| `softspotReactions` | 三个 key 各 3 条被扎中反应（llm.js 按 `softspotReactions[key] || stages[stage]` 兜底，**不许缺 key**） |
| `breakdown` | fire 房：3 条一次性破防词；**情商房：6–8 条暴怒常规台词池（见 §2.1，这是情商房开局语言）** |
| `finale` | `kind` 从现有 5 种选（`rapid`/`quit`/`recall`/`lights-off`/`read-none`）；情商房用「消气向」文案表达退场（§2.3）；不写 finale 则走通用兜底 |
| `guard` / `drift` | 按星档：d1 `1.0 / 0`；d2 `1.0 / 0`；d3 `0.95 / 2`；d4 `0.9 / 2`；d5 `0.85 / 3` |

## 2. 情商房（extinguish）写作规则 —— 本 spec 最重要的一节

引擎不变，只是同一套字段在灭火局里的**语义反转**（阶段区间 `duel-engine.js` STAGES：polite 0–35 / sarcastic 35–65 / agitated 65–85 / breakdown 85–100；情商房开局怒气 100）：

1. **`breakdown` 就是开场白池**：开局处于 breakdown 段（85–100），玩家最先听到的是这里的台词。写 6–8 条「暴怒/崩溃输出」，是这个场景里对方最凶也最真实的状态，而不是一次性破防演出词。
2. **stages 三键按消气阶梯写**（与 fire 房方向相反）：
   - `agitated`（65–85）：还在气头上，攻击性仍在但开始有缝隙
   - `sarcastic`（35–65）：怨气未消，阴阳/翻旧账/口是心非
   - `polite`（0–35）：接近消气，语气软下来、给台阶能接住
3. **`delta` 仍按「激怒量」直觉填正数**：引擎对 extinguish 统一翻转符号，软肋命中=高效降温，不需要写负数。
4. **`finale` 消气退场**：kind 复用现有演出，`lead` 写缓和台阶词（如「行吧，是我有点上头」）、`exitLine` 写消气离场通知（如「对方消气退出了聊天」）。演出机制零改动，全靠文案表达。
5. **玩法目标**：把怒气从 100 哄到 ≤20 判胜；8 回合没哄到=输。软肋=灭火抓手，三把「钥匙」要能被玩家从对方台词里**听得出来**（keywords 必须在 opener/stages/breakdown 里有语义铺垫，不能凭空猜）。

## 4. 验收（每批次交付时）

1. `smoke.mjs` 增「人设数据完整性」节（一次性实现，B1 起生效）：每个 persona 必填字段齐全、`softspots.length===3` 且 keywords 非空数组、`stages` 三键各 ≥1 条、`softspotReactions` 三键齐、`delta` 在 20–40 域、`category` 合法、`id` 唯一、`guard∈[0.7,1.3]`/`drift∈[0,5]`
2. `dom-check` 情商房用例（B1）：选情商房人设 → 完整对局 → judge 走 extinguish 分支 → 战报正常
3. 每人设手测一场：三个软肋都能被自己的 presets 或自然话术命中；开局/中盘/临近消气三段台词不穿帮（情商房重点听 breakdown 开场是否自然）
4. 开发者通读文案后入库；文案口径与现有 5 人设一致（口语、无 emoji 图标、无英文夹注）
