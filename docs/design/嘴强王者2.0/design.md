# 嘴强王者 2.0 · 设计意图

1. 定位升级：从「杠精陪练房」单一杠精对话，升级为多场景话术竞技平台「**嘴强王者**」。场景分三间房——杠精房（杠精网友/阴阳怪气亲戚）、谈判房（画饼老板/砍价摊主/甲方）、情商房（哄人/说服）。

2. 分类切在**选人屏**，大厅三模块卡结构不动；情商房本轮只上框架——分组可见、「即将开放」占位，人设内容后续走 `personas.js` 数据通道补（同 A1 模式），不阻塞也不被阻塞。

3. 情商房玩法是**灭火反向局**：对方怒气 100 起步（正在气头上），把怒气哄到阈值下=赢，说错话反弹。引擎只翻数值方向与胜负判定，数值体系（软肋 delta、递减、自爆、阶段）全复用——谈判房与杠精房仍是点火局，行为零变化。

4. 改名「嘴强王者」，英文副标 TALK KING；原「杠精陪练房」名号由杠精房分组继承。「话术健身房」平台叙事继续只活在文档里，不进 demo（纪律不变）。

5. 改名只动**展示层**：标题/品牌/水印/文件名/提示词/日志前缀/README/package.json。localStorage 键 `gang-ai:*`、部署域名、既有引擎常量与判定语义一律不动——存量玩家的主题/皮肤/设置不能丢。

6. 标记 2.0.0：`package.json` version 升 2.0.0，README 按三场景重写简介。
