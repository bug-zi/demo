# 好友擂台

> 对应源码：`src/data/scenarios.js`、`src/lib/arena.js`、`src/ui/arena.js`、`src/ui/arena.css`、`src/lib/llm.js`（评委段）、`scripts/arena-check.mjs` ｜ 已落地（260911）

## 是什么

同屏 hot-seat 两真人 PK：随机抽一张高压对话场景 → P1 限时 60 秒作答 → **交接屏**（遮住答案防偷看）→ P2 作答 → AI 评委逐轮打分（0-10 + 毒舌短评）→ 3 轮后终盘复盘（胜者 / 逐轮战报 / 全场金句 / 双方终评）。先答权逐轮轮换，连续后答不吃亏。

零服务、零网络通信依赖（远程双设备版明确留给赛后）；**全项目唯一强依赖远程 AI 的模块**——评分与复盘想要真模型的判断力。

## 流程与状态

- 视图相位机（`ui/arena.js` 闭包）：`intro → scene(先答) → handoff → scene(后答) → judging → reveal →（循环｜）judging → recap`，整相位重绘。
- **离场即弃局**：擂台中途「← 大厅」直接放弃整场（对局的「切走不销毁」不适用——3 轮 ×2 分钟的轻局，续局价值低于状态机成本）；大厅主卡不挂擂台角标、不进 `state`。`createArenaView` 返回 `{root, dispose}`，main.js 每次重绘前 `disposeArena()` 清掉答题倒计时 interval + 置 disposed，在途回调一律 no-op——不留幽灵计时器。
- 答题限时固定 60 秒（到点自动交卷，空答记「弃权」），不接对局设置里的回合时限——擂台是派对局，紧张感是特性。
- 场景卡只亮 title/setup/line；`hint`（评分口径）与 `keywords/traps`（本地粗评分点）**永不进 UI**——亮出来就是送分题。

## 引擎（`lib/arena.js`，独立于 duel-engine）

- 常量：`ARENA_ROUNDS=3`、`ARENA_ANSWER_SECONDS=60`、`ARENA_MAX_CHARS=120`；`drawScenarios` 部分洗牌抽不重复卡（rand 可注入）。
- **胜负唯一正本是 `arenaResult()`**：总分累加、平分即平局——AI 复盘只产文案与金句，与引擎判定冲突时以引擎为准（延续「模型建议、引擎结算」哲学）。
- 本地粗评 `localScore`（确定性）：base 4 + 命中 keyword +2（封顶 +6）− 踩雷 −3（场景 traps ∪ `GENERIC_TRAPS`，封顶 −9）+ 长句(≥12 字) 1；<4 字封顶 2；钳 0..10。`localRecap`：金句取全场单轮最高分（同分取更早轮，全 0 无金句）。

## 评分适配（`llm.js` 评委段）

- `judgeArenaRound({scenario, names, answers})` → `{p1:{score,comment}, p2:{…}, source, fallback?}`；`arenaRecap({arena, scenarios})` → `{summary, p1Comment, p2Comment, golden, winner, source, fallback?}`。
- 双 provider 复用公共请求核 `anthropicJson` / `openAiJson`（本次从 turn 路径抽出，response_format 重试与提醒重试只活一份）；评分 schema 0-10 整数 + ≤30 字短评，复盘 schema 含金句摘录（必须抄原话）。
- 收敛规则：任一侧 score 非有限数 → 整笔降级本地粗评（不静默造假分）；golden 摘不干净置 null；winner 非法收敛 draw。
- **降级路径**：无 key / 调用失败 → 本地粗评 + `fallback` 人话原因 + 终盘「未接入 AI：本场为本地粗评」提示行与「接入你的 AI →」入口——不留死路。本地关键词法评不了自由文本的不对称性即由此显式标注。
- 顺手修复：贴纸轮引入的 `anthropicTurn` ctx 引用 ReferenceError（Anthropic 通道一调用即被吞成本地降级），smoke 6.12 假 fetch（真 `Response` 形状）回归锁定。
