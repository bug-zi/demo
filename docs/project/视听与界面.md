# 视听与界面

> 对应源码：`src/styles.css`（全部样式）、`src/lib/theme.js`（主题与皮肤状态）、`src/data/skins.js`（皮肤登记表）、`src/ui/skin-popover.js`（皮肤弹层）、`index.html`（外壳）、`src/lib/audio.js`

## 外壳（index.html）

顶栏 = 品牌「杠精陪练房 GANG.AI」+ 引擎徽章（js 启动时填 `本地引擎`/`真实 AI · 模型名`）+ 皮肤按钮（palette）+ 主题切换按钮 + 设置按钮 + 声音开关。`<head>` 内联防闪脚本：渲染前读 localStorage 双键——`gang-ai:theme`（无记录跟随 `prefers-color-scheme`）设 `<html data-theme>`；`gang-ai:skin` 为 midnight 时设 `<html data-skin>`（默认 blossom 不必设）。`#app` 最大宽 760px 居中，`#screen` 为唯一挂载点，`aria-live="polite"`。

## 主题与皮肤机制（theme.js / skins.js）

**双属性正交**：`data-theme="light|dark"`（深浅）× `data-skin="blossom|midnight"`（皮肤）。两套皮肤各配深浅两模式共**四态**，全部走 CSS 令牌。

- 主题 API：`getTheme/applyTheme/toggleTheme/onTheme/initTheme`（键 `gang-ai:theme`）——入口 = 顶栏主题按钮 + 设置弹窗「外观」两段控件。
- 皮肤 API：`getSkin/applySkin/setSkin/onSkin/initSkin`（键 `gang-ai:skin`，默认 blossom）——订阅广播与主题同款。
- 皮肤登记表 `src/data/skins.js`：id/名称/一句话描述/浅深双色小样，是皮肤弹层唯一数据源，**加皮肤只改这里**（再在 styles.css 补令牌块）。

切换即时生效（颜色 0.2s transition，reduced-motion 下关闭）。战绩图 Canvas 读令牌，自动跟随皮肤与深浅，零改动。

## 图标体系（Material Symbols Outlined，自托管）

全 App 禁 emoji，统一线性图标：SVG 拷贝自 `@material-symbols/svg-400@0.47.2` 存于 `public/assets/icons/`（14 个，零运行时依赖），CSS `mask-image + currentColor` 渲染（`.icon .i-*` 类，url 绝对路径）。清单：settings / palette / check / volume_up / volume_off / light_mode / dark_mode / close / star / target / bolt / keyboard / theater_comedy / cake。

人设头像 = `.avatar` 主题色淡底圆 + 线性图标（网友 keyboard、亲戚 theater_comedy、老板 cake）；难度 = `star` ×n + 降透明度 ×(5-n)；判定标签带 target（软肋）/ bolt（自爆）图标；皮肤弹层 active 卡带 check。

## 关键组件（按屏）

**选人屏**：hero 标题「把对面说破防」+ persona-grid 卡片（头像/名字/星级/台词/简介），hover 抬升。

**对线屏**：怒气条（fill 宽度=怒气%、颜色随 data-stage；35/65/85 刻度线）；stage-pill（blossom 实底药丸 / midnight 素底彩字）；气泡流（对方左带头像、我方右）；typing 三点 blink；quip 行（判定标签+图标+Δ值）；预设 chips 用后置灰；计时 ≤10s 红显。

**报告屏**：result-badge 三态、title-card（rank 徽章=accent 底）、stats 网格、replay 列表（判定图标）、三按钮。战绩图 `exportCard()` 颜色读 CSS 令牌，导出跟随当前皮肤×深浅。

**皮肤弹层**（skin-popover.js）：顶栏 palette 按钮触发，挂 body 不走 render()，对线中随时打开**不暂停计时**；两张皮肤卡（名称/描述/浅深双色小样静态预览），点卡即切皮肤且**弹层保持打开**便于对比，active 卡带 check 勾；Esc / 点外部关闭。

## 响应式与无障碍

`@media (max-width: 560px)` 单列适配（皮肤弹层同宽适配）；`prefers-reduced-motion` 关动画与过渡；`:focus-visible` 用 --accent-strong 描边；纯图标按钮均有 aria-label。

## 声音（audio.js）

WebAudio 现场合成，零音频文件；默认静音，顶栏开关 opt-in。6 种配方：send / reply / hit / softspot / self_destruct / breakdown。禁用时 `blip()` no-op，非阻塞。
