# 总览

> 对应源码：整个 `src/` ｜ 面向队友与评委的项目入口

## 一句话

嘴强王者（TALK KING，v2.0.0）：按场景分三间房选对手对线——杠精房/谈判房是点火局（把对方怒气怼到 100 让他当场破防），情商房是灭火局（对方怒气 100 起步，哄到消气才算赢），赛后领一份可下载 PNG 的《对线战力报告》；大厅还挂着话术资料库（120 条内置话术 + 收藏 + 自建笔记，见 [话术资料库.md](话术资料库.md)）与好友擂台（同屏两真人 hot-seat PK + AI 评委逐轮打分 + 终盘复盘，见 [好友擂台.md](好友擂台.md)）。

## 技术栈

- Vite + 原生 ES Modules：无框架、无路由、无后端，`npm run build` 出纯静态站
- 可选远程 AI：`@anthropic-ai/sdk` 动态导入，配 `.env.local` 的 `VITE_LLM_API_KEY` 生效；失败静默降级本地引擎，离线可完整对局
- 回归检查：`npm run smoke`（引擎规则无头测试）、`npm run dom-check`（jsdom 驱动真实入口的 UI 流程测试）、`npm run library-check`（资料库模块独立测试，不 import main.js）、`npm run arena-check`（擂台模块独立测试：数据/引擎/评分适配/视图）

## 六屏状态机（src/main.js）

`lobby`（模块大厅，初始屏）→ `select`（选人，三房分组）→ `duel`（对线，点火/灭火）→ `report`（战报）；`library`（话术资料库）与 `arena`（好友擂台）从大厅真卡进入，随时可回

- 大厅三张模块卡全解锁：对线房主卡（进行中对局带「对局进行中 · 第 N 轮」角标）+ 话术资料库真卡 + 好友擂台真卡（离场即弃局，不挂角标）；主卡有活局进对线续局，否则进选人
- 选人屏按 `src/data/categories.js` 三房分组：杠精房（点火局）/ 谈判房（点火局）/ 情商房（灭火局，「即将开放」占位）；人设挂 `category` 字段归房，未标注兜底归杠精房
- 切去大厅不清对局：记录在 `state.duel`，回对线由 `viewDuel()` 从 `duel.rounds` 整屏重建，倒计时续剩余秒数；AI 回复中离场则回合离线记账、回来补画
- `render()` 按 `state.screen` 清空重建视图；DOM 用本地 `h()` 帮助函数构造，所有文本走 `textContent`，绝不拼 HTML
- 对局中的怒气条、计时、日志走 `refs` 增量更新，不整屏重渲染

## 一回合的数据流

`submitTurn()`（main.js）→ `generateTurn()`（llm.js：远程 Claude 或本地模板，统一返回 `{reply, hitType, softspot, quip, source}`）→ `recordTurn()`（duel-engine.js：怒气结算、胜负判定的**唯一权威**，模型只建议 hitType）→ 增量更新日志/怒气条 → `judge()` 出结果则 `finish()` → report 屏 `pickTitle()` + `exportCard()` Canvas 导出

```text
src/ui/settings-dialog.js  「接入你的 AI」设置弹窗（挂 body 不走 render()，打开即暂停计时）
src/ui/library.js     话术资料库视图（createLibraryView 自包含，见 话术资料库.md）
src/ui/library.css    资料库专用样式（纯令牌，与 styles.css 分立）
src/ui/arena.js       好友擂台视图（createArenaView 自包含 + dispose 契约，见 好友擂台.md）

src/data/providers.js AI 服务商预设（PROVIDER_OPTIONS / presetList）
src/lib/duel-engine.js 规则层：怒气/阶段/判定（数值唯一权威；fire 点火 / extinguish 灭火双模式）
src/lib/arena.js      擂台记分引擎（hot-seat 抽卡/记分/判胜 + 本地粗评，独立于 duel-engine）

src/lib/audio.js      WebAudio 合成音效（默认静音）
src/lib/dom.js          h() DOM 构造助手（安全 DOM 渲染公共件）
src/lib/settings.js     AI 设置读取/保存/清除/脱敏（localStorage）
src/lib/notes.js        资料库收藏/笔记存储层（localStorage，坏数据收敛，见 话术资料库.md）
scripts/smoke.mjs     引擎无头回归
scripts/dom-check.mjs jsdom UI 流程回归
scripts/library-check.mjs 资料库模块独立回归（数据/存储/视图三节）
scripts/arena-check.mjs  擂台模块独立回归（数据/引擎/评分适配/视图四节）
```

## 环境与命令

`npm install` / `npm run dev`（5173 端口）/ `npm run build` / `npm run preview` / `npm run smoke` / `npm run dom-check` / `npm run library-check` / `npm run arena-check`。远程 AI 的环境变量说明见根目录 `CLAUDE.md`「Optional remote AI configuration」。

## 平台愿景

终局形态是「话术健身房」多场景高压对话陪练平台（叙事只进文档不进 demo）。2.0 已落了第一层：分类三房 + 灭火反向局；「类=房=新指标」的深水区见方案库素材。扩展铁律：改数据（`src/data/`）不改骨架（引擎/UI 不硬编码人设）。
