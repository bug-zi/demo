# 话术资料库

> 对应源码：`src/data/comebacks.js`、`src/lib/notes.js`、`src/ui/library.js`、`src/ui/library.css` ｜ 入口：大厅「话术资料库」真卡 → `library` 屏

## 是什么

对线之外的第二个模块：120 条内置回怼/自保/降温话术随身查阅，☆ 收藏攒必杀句，自建笔记记自己的句子。全部数据在玩家本地 localStorage（`gang-ai:favorites:v1` / `gang-ai:notes:v1`），无广场无 UGC，清缓存即失。设计正本见 `../design/话术资料库/`（spec 已归档至其 `archive/`）。

## 四件套结构

```text
src/data/comebacks.js  内容层：SCENES（8 场景）/ TYPES（3 类型）登记表 + COMEBACKS 120 条
                       { id(c001…), text, scene, type, tip(何时用), tags[] }
src/lib/notes.js       存储层：收藏 + 笔记读写 localStorage；纯函数（toggle/upsert/delete）
                       与落盘分离，坏数据逐条收敛、storage 不可用安静降级
src/ui/library.js      视图：createLibraryView({getter × 持久化回调 × onBack})，main.js 挂
                       library 屏；筛选/搜索/表单状态在闭包，列表区局部重绘（输入不丢焦点）
src/ui/library.css     样式：纯四态令牌零写死色，由 index.html <link> 加载，与 styles.css 分立
```

## 筛选与交互

- 四条筛选轴：场景（全部 / 8 场景 / 自建）、类型（全部 / 反击·自保·降温）、仅收藏 ★、搜索（text/tip/tags includes）
- 笔记排在列表最前（自己的东西先看到），带「自建」徽标 + 编辑/删除；内置话术带 ☆/★ 文本星标
- composer 新建/编辑共用：话术必填（空则卡片下方报错，不弹窗）、场景/类型取真实登记表（「自建」只是来源筛选轴，不是伪场景——笔记自然落入场景浏览）
- 「← 大厅」随时返回；对局进行中去资料库往返不影响「对局进行中」角标（大厅对局永不销毁）
- 渲染铁律与全站一致：全部经 `h()` textContent，无 innerHTML；模块日志前缀 `[话术资料库]`

## 内容运营（怎么改话术）

- **人工筛 = 直接删改 `comebacks.js`**：一行一条，删出 id 空洞无妨（id 只是收藏引用的稳定标识）
- 底稿：`../draft/260911-资料库话术初稿.md`（8 场景 × 15 条，与文件行序一致）
- 数据校验由 `npm run library-check` 第 1 节强制：id 唯一、text/tip 非空、scene/type 在登记表内、tags 为非空字符串数组、8 场景各 ≥10 条、三类型各 ≥15 条

## 回归

- `npm run library-check`：三节——数据完整性 / 存储纯函数（含坏数据与无 storage 降级）/ jsdom 视图交互（筛选×搜索×星标×自建增删改×返回，全树无 innerHTML）；不 import main.js，模块独立可测
- `npm run dom-check` 第 13 节：大厅解锁进入 → 筛选/收藏/自建落 localStorage → 返回 → 对局角标不受影响
- 四态（2 皮肤 × 2 深浅）令牌采样验收过：`.entry-card` 底=--surface、星标选中=--accent-strong、meta=--muted、tag=--surface-deep 逐一吻合；桌面/390px 移动端均无横向溢出
