# 成长系统

> 对应源码：`src/lib/profile.js`、`src/lib/ladder.js`、`src/data/achievements.js`、`src/data/titles.js`、`src/ui/wall.js` + `wall.css` ｜ 心池/经济数值正本在 `profile.js` 的 `ECONOMY` 表，对局数值见 [对线规则.md](对线规则.md)

## 一句话

3.0 在「三房对线」骨架上叠了一层玩家成长：选人屏是**全开放关卡梯 + 推荐路线**（18 关直接可打，每房第一个未通关的关高亮「推荐」），输了掉心、赢了给金币经验、升级发币，36 条成就产币产称号（成就墙佩戴），设置里有演示模式（无限生命）兜底现场演示。设计正本（已归档）：`../design/3.0成长系统/archive/`。

## 玩家档案（`gang-ai:profile:v1`，唯一数据层 `src/lib/profile.js`）

| 字段 | 说明 |
|---|---|
| `xp` / `level` / `coins` | 经验 / 等级 / 金币 |
| `hearts` + `lastRegenAt` | 心池（上限 5）+ 恢复记账起点（**读时惰性结算**：无后台定时器，离线也在回心；满血时重置起点防陈年余数） |
| `cleared: { gang:[], deal:[], eq:[] }` | 房 → 已通关关卡序号（0 起）；关卡数据不落盘，加人设自动长梯 |
| `achievements` | 成就 id → 解锁时间戳 |
| `titlesOwned` / `equippedTitle` | 称号图鉴与佩戴（单选） |
| `demoMode` | 演示模式（无限生命；设置弹窗「对局」组开关，即时生效） |
| `stats` | 对线/战役/资料库/擂台/收集全套计数（成就谓词只读这里） |
| `processedDuels` | 已结算 duelId FIFO 封顶 50（战报反复渲染不重算） |

防御姿势照 `settings.js`：解析失败 / schema 版本不符 → 整档重置；坏数值收敛为非负整数。

## 经济数值（ECONOMY 表，调平衡只改这一处）

| 项 | 值 |
|---|---|
| 心 | 上限 5，败局 −1（draw/win 不扣），30 分钟自然回 1，50 币买 1（`buyHeart` 三态：ok / no_coins / full） |
| 胜局 | 经验 `30 + 10×难度`；金币首通 `50 + 20×难度`，**复刷 ×0.3 向下取整**（经验照发） |
| 负局/和局 | 经验 15，金币 0 |
| 升级 | `XP_TO_NEXT = 100 + (level−1)×50`，升级 +100 币，每满 5 级送 1 心（封顶） |
| 成就 | bronze 50 / silver 100 / gold 200 / king 300 币（v1 只发币，hearts 字段保留不填） |

**结算幂等**：`duel.settlement` 挂账 + `processedDuels` 账本双保险；离场时 AI 回合终局的局走「弃局」语义不入账。成就扫描点共五处：grantBattle / buyHeart / grantArena 尾部 + 进成就墙 + 资料库切场景；**对局成就只进战报结算区不进 toast 队列**，队列只收场外解锁（右下角 3s 自消）。

## 房内关卡梯（`src/lib/ladder.js`，纯函数零落盘）

- `ladderFor(roomId)`：房内人设按 difficulty 升序排关，同星按 `personas.js` 数组序；**插入位置即关卡序**（B2 的 1→2→3→4→4→5 梯就是这么排的）
- **全开放，无锁定态**：18 关全部直接可打；`nextRecommended(profile, roomId)` 指向本房第一个未通关的关（UI 高亮「推荐」），通关账允许跳关空洞，全通返回 −1
- 三房进度独立；已通关随时复刷（金币按 0.3 档，判定在通关账写入**之前**）
- 对局携带 `duel.ladder = { roomId, levelIndex }`（引擎透明携带）；胜局写 `cleared[roomId]`（去重）

## 引擎阻力参数（`duel-engine.js`，按星档）

| 星 | guard | drift |
|---|---|---|
| d1 / d2 | 1.0（缺省免字段） | 0（缺省免字段） |
| d3 | 0.95 | 2 |
| d4 | 0.9 | 2 |
| d5 | 0.85 | 3 |

- **guard** 只乘玩家主动输出（软肋/有效输出/贴纸的 delta，mode 翻转后、clamp 前，四舍五入）；自爆与沉默豁免
- **drift** 是每回合环境漂移（fire 怒气下滑 / extinguish 回升），`recordTurn()` 在应用本回合 delta **之前**按新完成间隔增量补付——每回合只付一个新间隔，不是平方叠加；胜局最后一击永不被漂移吞掉

## 成就墙与称号（`src/ui/wall.js`，`createWallView({getProfile, onEquipTitle, onBack}) → {root, dispose}`）

- **36 条成就 × 6 类分区**（对线/战役/资料库/擂台/收集/隐藏），bronze 15 + silver 12 + gold 7 + king 2；每条是 `{id, name, desc, group, tier, coins, check(p, ctx)}` 纯读谓词——新增成就 = 追加表行，UI/引擎零改动
- 隐藏成就 6 条，未解锁显示 ???；房通关类经 `ladderFor()` 派梯，**空房不算通关**
- **称号双源**：赛后 `pickTitle()` 在 `settleDuel()` 里、grantBattle 扫描**之前**入册（同局「名满天下」即生效）；成就 `title` 字段是第二来源（专属称号「甲方收割机」）。全图 `ALL_TITLES` = 8 赛后 + 1 成就专属 = 9 枚
- **佩戴四处同步**：大厅名片卡、对局 meta 行、战报结算区、分享卡 PNG（`exportDuelCard` 的 `wornTitle`）
- 模块挂勾最小侵入：`library.js` 可选回调 `onSceneViewed`、`arena.js` 可选回调 `onArenaEnd`（终盘 paintRecap 恰好上报一次，win 口径 = 分出胜负）；旧调用方不传即无感

## M6 数值平衡结论（260912 推演，脚本 `out/balance-sim.mjs`）

- 全程 18 胜零败：总经验 1120 → **Lv.6**；升级坡度前紧后松（前期 2–3 胜一级 → 后期 5–9 胜一级）
- 理论收入上限 = 首通 2060 + 升级币 500 + 成就币 3950 = **6510**；唯一硬消费是买心 50/颗，且心池封顶 5——消费端天然有界，通胀无实害
- 复刷币恒低于买心价（d5 复刷 45 < 50）——**复刷不可养活买心，防刷成立**；复刷经验照发，长线升级约 9 场复刷一级（d5）
- 心经济无死锁：连败 5 局才触底，回 1 心 = 30 分钟或 50 币（一场 d1 首通 70 就够），另有演示模式兜底
- ECONOMY 表**零调整**；B3 若加人设，首通币与关卡自动按表增长
