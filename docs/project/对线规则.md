# 对线规则

> 对应源码：`src/lib/duel-engine.js` ｜ 本文件是数值规则的文档镜像，改引擎必同步这里

## 两种模式（mode，来自人设所属分类 categories.js）

| 模式 | 房间 | 初始怒气 | 赢 | 增量方向 |
|---|---|---|---|---|
| fire 点火局 | 杠精房 / 谈判房 | 0 | 怒气 ≥100 | 软肋/有效输出加分，自爆减分 |
| extinguish 灭火局 | 情商房（装修中） | 100 | 怒气 ≤20（EXTINGUISH_WIN_ANGER） | 整体翻转：戳心结/安抚降怒，自爆反弹 +12 |

灭火局无平局：8 轮没哄好直接判 lose。judge() 必须先看 mode 再比怒气（灭火局开局即 100，沿用 fire 的 ≥100→win 会首回合误判）。

## 核心常量

| 常量 | 值 | 含义 |
|---|---|---|
| MAX_ROUNDS | 8 | 一局最多 8 轮 |
| ROUND_SECONDS | 30 | 每轮倒计时，超时按沉默结算 |
| MAX_SELF_DESTRUCTS | 2 | 累计 2 次自爆判负 |
| MAX_ANGER | 100 | 怒气上限，达到即破防胜 |
| EXTINGUISH_WIN_ANGER | 20 | 灭火局胜线（降到礼貌段深处才算消气） |

## 怒气增量 ANGER_DELTA

| hitType | Δ（fire） | Δ（extinguish） | 本地判定条件（localHitType，先去空白） |
|---|---|---|---|
| softspot | 软肋自带 delta（28–34）；同一软肋第二次起 ×0.5 | 同值取负（灭火局的「软肋」=心结） | 命中任一软肋 keywords（子串匹配） |
| hit | +12 | −12（有效安抚） | ≥8 字且含 HIT_HINTS 信号词（但是/因为/所以/请问/你刚才/凭什么…15 个），或 ≥18 字 |
| miss | 0 | 0 | 其余一切输入（包括沉默） |
| self_destruct | −12 | **+12（火上浇油，反弹）** | 命中 SELF_DESTRUCT_HINTS 骂人词表（13 个），或 `!!!`/`???` 连打 |

灭火局的数值自洽：eq 人设三心结 delta 和 ≈90（与现有人设同标尺），找齐三个心结再补一句有效安抚 = 100−90−12 → 落到胜线下；纯 miss 永远赢不了——「不找心结就别想哄好」与点火局同构。

远程模式下 hitType 由模型判定（提示词里给了判据），本地判定仅作无 key 与降级时的兜底；**无论谁判，怒气数值一律由 `recordTurn()` 查表计算**。

## 情绪阶段 STAGES（stageOf 按怒气取最高满足 min 的阶段）

| 阶段 | 区间 | 标签 | UI 色 |
|---|---|---|---|
| polite | 0–35 | 礼貌 | #8FA88F |
| sarcastic | 35–65 | 阴阳 | #FFD24A |
| agitated | 65–85 | 上头 | #FF9A4D |
| breakdown | 85–100 | 破防 | #FF4D4D |

## 回合结算（recordTurn）

- 怒气 clamp 到 [0,100]；自爆计数 +1；`usedPreset` / `freeTextRounds` 分别累计（供称号判定）
- 每轮记录 `{round, userText, aiReply, hitType, quip, delta, angerAfter, stage, softspotKey}`
- judge() 判定顺序：自爆 ≥2 → **lose**；灭火局先看 mode（怒气 ≤20 → win；满 8 轮 → lose）；点火局怒气 ≥100 → **win**；满 8 轮 → **draw**

## 对局状态（createDuel）

`persona / personaId / mode(fire|extinguish) / anger(点火 0 起步·灭火 100 起步) / rounds[] / selfDestructs / softspotKeys[]（已命中的去重软肋）/ usedPresets / freeTextRounds / result`
