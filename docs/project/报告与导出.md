# 报告与导出

> 对应源码：`src/main.js`（viewReport / exportCard / RESULT_COPY + EQ_RESULT_COPY）、`src/data/titles.js`

## 报告屏（viewReport）结构

1. 结果徽章 + 副标题（按模式分套）：
   - 点火局：win「他破防了/你把对方聊到闭麦」· lose「你被反杀/两次自爆」· draw「打平/八轮谁也没破防」
   - 灭火局：win「TA 消气了/你把这场架温柔地摁灭了」· lose「没哄好/越哄越炸，或者时间到了」（无 draw）
2. 称号卡：rank 徽章 + 称号名 + 毒舌评语（点火/灭火两套称号表）
3. 六项统计：对手、回合数、软肋命中/心结命中 x/3、自爆次数 x/2、最终怒气 x/100、引擎（本地引擎 / 真实 AI · 模型名）
4. 对线回放：逐轮「你：… / 对手：… / 判定标签 +Δ」（标签按模式：扎中软肋/有效输出/自爆 ↔ 说到心结/有效安抚/火上浇油）
5. 操作：再来一局（同人设）/ 换个对手 / 保存战绩图

## 称号系统（titles.js，判定顺序先命中先得）

点火局（TITLES）：

| 称号           | rank | 条件                                                                                                |
| ---------------- | ------ | ----------------------------------------------------------------------------------------------------- |
| 被反杀的人     | N    | lose                                                                                                |
| 人形自走破防器 | SSR  | win 且 ≤4 轮且去重软肋命中 ≥2（当前数值下 3 轮破防在数学上不可能，4 轮全软肋+补刀是唯一达成路径） |
| 阴阳大师       | SR   | 其余一切 win（含拖满轮数的胜局）                                                                    |
| 弹幕型选手     | R    | draw 且 freeTextRounds=0（全程预设+沉默，没说过一句自己的话）                                       |
| 嘴笨但坚持     | R    | 其余 draw                                                                                           |

灭火局（EQ_TITLES，无平局）：

| 称号       | rank | 条件                                        |
| ------------ | ------ | --------------------------------------------- |
| 读心术大师 | SSR  | win 且 ≤4 轮且去重心结命中 ≥2               |
| 灭火队员   | SR   | 其余 win                                    |
| 火上浇油   | N    | lose（自爆 2 次或 8 轮没哄好）              |

## 战绩图导出（exportCard）

- Canvas 逻辑尺寸 720×1000，实际 ×2 绘制保清晰度，`toBlob` 下载 PNG，文件名 `嘴强王者-{称号名}.png`
- 版面（深夜底 #12100E + 顶 8px 怒气红条）：品牌字「嘴强王者 · TALK KING」→ 结果大字（56px）→ 对手 → 称号卡（rank 黄字 + 名称 + 折行评语）→ 4 行统计（灭火局「心结命中」）→ 底部金句「软肋这东西，人人都有一根。」+ 引擎标签
- 纯 Canvas 手绘，不依赖截屏，换屏不错位
