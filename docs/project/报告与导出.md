# 报告与导出

> 对应源码：`src/main.js`（viewReport / exportCard 薄壳 / RESULT_COPY + EQ_RESULT_COPY）、`src/lib/share-card.js`（战绩图）、`src/data/titles.js`

## 报告屏（viewReport）结构

1. 结果徽章 + 副标题（按模式分套）：
   - 点火局：win「他破防了/你把对方聊到闭麦」· lose「你被反杀/两次自爆」· draw「打平/八轮谁也没破防」
   - 灭火局：win「TA 消气了/你把这场架温柔地摁灭了」· lose「没哄好/越哄越炸，或者时间到了」（无 draw）
2. 称号卡：rank 徽章 + 称号名 + 毒舌评语（点火/灭火两套称号表）
3. 六项统计：对手、回合数、软肋命中/心结命中 x/3、自爆次数 x/2、最终怒气 x/100、引擎（本地引擎 / 真实 AI · 模型名）
4. 对线回放：逐轮「你：… / 对手：… / 判定标签 +Δ」（标签按模式：扎中软肋/有效输出/自爆 ↔ 说到心结/有效安抚/火上浇油）
5. 操作：再来一局（同人设）/ 换个对手 / 保存战绩图

## 战绩图导出（A3 传播化重做，`src/lib/share-card.js`）

- 目标标准**「脱离网页仍能看懂」**：对手（头像+名字）、结果、金句、称号、二维码一图齐全；`main.js` 的 `exportCard()` 只是薄壳（传 `{duel, copy, engine}`），绘制全在 `lib/share-card.js`
- **金句选取 `pickGoldenQuote(duel)`（纯函数，smoke 第 7 节覆盖）**：点火局取 delta 最大、灭火局取 delta 最小的回合（存档 delta 已被引擎翻转，方向即胜负方向）；无文字回合（纯斗图/沉默）不参选；无候选返回 null → 卡片走 `FALLBACK_QUOTE`「一场寂静的较量，没有一句话落在点上。」
- **版面**（Canvas 720×1000 逻辑尺寸 ×2 绘制，`toBlob` 下载 `嘴强王者-{称号名}.png`）：8px 怒气红条 → 品牌行「嘴强王者 · TALK KING」→ 结果大字+副标题（`RESULT_COPY`/`EQ_RESULT_COPY`）→ 对手行（人设头像圆 + 名字）→ 金句卡（琥珀标签「本局最痛一击 +Δ」/「本局最暖心一击 怒气Δ」+ 右侧你的气泡、左侧 TA 气泡，各最多 2 行截断）→ 称号卡（rank/名称/评语）→ 统计 2×2（回合数/软肋或心结命中/自爆/最终怒气）→ 底栏「扫码来战 + gang.debugzi.com + 引擎」+ 右下二维码
- **二维码**：`qrcode-generator`（唯一新增运行时依赖，MIT 零传递依赖）出矩阵自绘，编码正式链接 `https://gang.debugzi.com`，ECC M、白底黑码、8px quiet zone；生成失败降级为不放码（链接文字仍在）
- **头像**：fetch `/assets/icons/{avatar}.svg` 抽 path 以 Path2D 重绘，坐标系按 SVG 自带 viewBox 解析（这批自托管图标是 `0 -960 960 960` 的 960 系，不是 24 系——按 24 硬算会放大 40 倍泼出圆外）；失败降级为首字圆
- **配色**：固定品牌传播色写死在 share-card.js（深夜底 `#12100E` + 怒气红 `#D33A3A` + 琥珀金 `#F0C243`），不读会话令牌——传播资产要四态一致；写死色只进这块 Canvas，不违反 UI 层四态令牌纪律
- 容错链：头像/二维码失败各自降级，`toBlob` 失败静默返回，导出永不被外挂资源卡死
