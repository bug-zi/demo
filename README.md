# 杠精陪练房 · GANG.AI

> 把吵架做成一门有破防值条、有软肋、有赛后复盘的对线竞技。

**你的目标不是把道理讲赢 —— 是让对面先绷不住。**

传统对话式 AI 让你「说服」它。我们反过来：你和 AI 对线，任务是把对方聊到破防。
每个人设都藏着 2–3 个软肋，戳中了破防值飙升；但你自己说急了也会自爆两次直接判负。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:5173
```

不用配任何 key 就能完整玩一局 —— 默认走本地引擎。

```bash
npm run build      # 产物在 dist/，纯静态，扔哪都能跑
npm run smoke      # 不开浏览器：引擎路径 + 人设数据自检 + 远程通道解析与降级
npm run dom-check  # 用 jsdom 真跑一遍 UI：选人 → 对线 → 打完 → 报告
```

## 接真实 AI（可选）

**方式一：应用内填**（推荐，任何人拿到页面就能用）

点顶栏的 ⚙️，或者在选人屏底部点「接入你的 AI →」。选服务商、贴 key、点「保存」。
配置存在浏览器 localStorage 里，刷新不丢，随时可以点「清除」退回本地引擎。

支持两条通道：

| 通道 | 覆盖 | 说明 |
|---|---|---|
| Claude | Anthropic 官方 API | 走官方 SDK，浏览器直连可行 |
| OpenAI 兼容 | DeepSeek / 通义 / Kimi / 智谱 / Ollama / 自建网关 | `POST {baseUrl}/chat/completions`，内置一键预设 |

弹窗里有「测试连接」，会把失败原因翻成人话（key 无效 / 模型名不对 / 跨域被拦 / 限流）。

> ⚠️ **跨域是服务商侧的限制。** 不少 API（比如 OpenAI 官方）不允许浏览器直接调用，
> 填对了 key 也连不上 —— 这时得换成允许跨域的服务商，或者自己搭个代理填进 Base URL。

> ⚠️ **别用推理型模型**（deepseek-reasoner、R1、o1 之类）。它们的思考过程和答案共用
> `max_tokens`，对话一长，思考就把额度吃光，接口返回 200 但 `content` 是空的 ——
> 表现就是「前两轮正常，之后开始本地兜底」。用对话模型（deepseek-chat / qwen-plus 等）更稳。

**方式二：写 `.env.local`**（团队自己 demo 用，优先级低于界面里填的）

```bash
cp .env.example .env.local   # 然后填 VITE_LLM_API_KEY
```

配好之后，顶栏徽章会从「本地引擎」变成「真实 AI · 模型名」。

---

无论走哪条通道，**破防值始终由前端算** —— 模型只负责台词、判定和一句杀伤力分，
抽风也不会把游戏搞坏（下面的 80/20 就是为这件事设计的）。调用失败会自动降级回本地引擎，
并在聊天流里插一行「本地兜底 · 真实 AI 没接上：<原因>」—— 不打断对局，
但你能一眼看出这回合是谁在说话。完整报错在浏览器控制台（`[杠精陪练房] 真实 AI 调用失败…`）。

> ⚠️ key 存在浏览器里 / 会被打进前端产物，只适合本地演示。要正式上线得换成一个后端代理。

## 玩法

| | |
|---|---|
| 回合 | 最多 8 轮 |
| 难度 | 选人屏上选，只改每回合的输入时限：**噩梦 30s / 困难 45s / 简单 60s**（默认困难）。胜负规则三档完全一样 |
| 主题 | 顶栏 ☀️/🌙 切换暗色（默认）/ 亮色，选择存在浏览器里 |
| 表情 | 输入框左边的 😀，点一个插到光标处（27 个，按语气从轻到重排，悬停有用途提示） |
| 赢 | 对方破防值到 100 |
| 输 | 自己自爆 2 次 |
| 平 | 8 轮打完谁也没破防 |

### 破防值怎么算：查表 80% + 判断 20%

```
每回合涨幅 = 查表值 × 80% + 判断分 × 20%
```

**查表那 80%**（骨架，确定的部分 —— 戳没戳中软肋、有没有自爆）：

| 判定 | 涨幅 |
|---|---|
| 软肋 | +28~32（每个软肋自带；同一个反复戳减半） |
| 有效输出 | +12 |
| 无效输出 | 0 |
| 自爆 | −12 |

**判断那 20%**（这句话到底多有杀伤力）：远程由模型给（prompt 里写了锚点：30 正中软肋 /
12 有道理 / 0 不痛不痒 / 负数在露怯），本地由 `localJudge()` 按复读、长度、标点、
有没有引用对方来打分。判断分被夹在 **−15 ~ 35**，且判断分等于查表值时结果正好等于查表值 ——
所以「三个预设刚好 90、补一句破百」的配平在两条通道上都不会散架。

每回合的算式会印在报告页的回放里（`查表 +12 × 80% + 判断 +30 × 20% = +16`），
鼠标悬在聊天流的结算小字上也能看到。

**表情只表达语气，不参与判定。** 加表情不会涨破防值，也不会把废话变成有效输出 ——
判定前会先把 emoji 摘掉再看字。这不是洁癖：emoji 在 UTF-16 里占两个单位，
九个表情就是 18 个字符，正好够上「说了句有内容的」那条线，不拦就等于点九下白拿 +12。
（输入框旁边的计数也是为这个 —— 一个表情吃两格，不写出来玩家会以为卡了。）

情绪分四档，破防值越高对方越失控：**礼貌 → 阴阳 → 上头 → 破防**。

预设话术点一下直接发。只用预设不补刀的话，破防值会卡在 90 打平 —— 想赢还是得说点自己的话。

**唯一的例外是甲方（★★★★★）**：他的三个预设里有一个是诱饵。「我这就去改，您别生气」听着像
敷衍，其实是甲方最爱听的答案 —— 点下去 0 分，白扔一个回合，换来他一句高高兴兴的「对对对，
就是这个感觉」。所以要赢他，得自己把第三个软肋问出来。

## 目录

```
index.html            应用外壳
src/
  main.js             状态机 + 四个界面（选人 / 对线 / 结局 / 报告）
  styles.css          深夜聊天窗配色
  data/
    personas.js       5 个人设：软肋、四阶段台词、破防台词
    titles.js         赛后称号判定
    fallbacks.js      判定标签、通用兜底台词
    difficulty.js     三档难度（只改每回合输入时限）
    emojis.js         表情面板的内容：27 个，按语气排序，每个配一句用途提示
    providers.js      服务商清单与一键预设
  lib/
    duel-engine.js    破防值 / 情绪阶段 / 软肋判定 / 胜负
    llm.js            大脑适配层：本地 / Claude / OpenAI 兼容，同一套返回值
    settings.js       用户填的 AI 配置，存 localStorage
    theme.js          暗色 / 亮色，只往 <html data-theme> 上挂个名字
    text.js           输入上限 / 摘掉表情 / 别把 emoji 切成半个
    audio.js          WebAudio 现场合成音效，不加载任何音频文件
    dom.js            h() —— 所有文本走 textContent，绝不拼 HTML
  ui/
    settings-dialog.js   「接入你的 AI」弹窗
    emoji-picker.js      表情面板：插到光标处，不管判定
scripts/
  smoke.mjs           无头冒烟测试：引擎路径 + 人设数据自检 + 远程通道解析与降级
  dom-check.mjs       jsdom 里真跑一遍界面，含设置弹窗
```

人设、软肋、台词全是数据，加一个对手只需要往 `src/data/personas.js` 里加一条，
再跑一次 `npm run smoke` —— 那段人设自检会逐个断言星级、软肋合计 90、预设命不命得中、
关键词有没有互相盖住（`匹配是先命中先赢`），缺什么它会直接点名。选人屏和测试里的对手
数量都从 `PERSONAS` 推导，不用跟着改。
