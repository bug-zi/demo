# 嘴强王者 · TALK KING

> 把说话做成一门有怒气条、有软肋、有赛后复盘的竞技 —— v2.0.0，多场景三间房。

**杠精房、谈判房点火开局：你的目标不是把道理讲赢 —— 是让对面先绷不住。**
**情商房灭火开局：对方正在气头上，你的目标是几轮之内把 TA 哄到消气。**

传统对话式 AI 让你「说服」它。我们反过来：你和 AI 对线，按场景分房开打。
每个人设都藏着 2–3 个软肋（情商房是「心结」），戳中了怒气值飙升；但你自己说急了也会自爆两次直接判负。

- **杠精房**（点火局）：杠精网友 / 阴阳怪气亲戚 —— 把 TA 说到破防
- **谈判房**（点火局）：砍价摊主 / 画饼老板 / 五彩斑斓甲方 —— 同样点火，对手换人
- **情商房**（灭火局，装修中）：哄人 / 说服 —— 对方怒气 100 起步，哄到消气才算赢

## 跑起来

```bash
npm install
npm run dev      # http://localhost:5173
```

不用配任何 key 就能完整玩一局 —— 默认走本地引擎。

```bash
npm run build      # 产物在 dist/，纯静态，扔哪都能跑
npm run smoke      # 不开浏览器，验证引擎路径（含灭火局反向判定）
npm run dom-check  # 用 jsdom 真跑一遍 UI：大厅 → 选人 → 对线 → 打完 → 报告
```

## 接真实 AI（可选）

**方式一：应用内填**（推荐，任何人拿到页面就能用）

点顶栏的 ⚙️，或者在选人屏底部点「接入你的 AI →」。选服务商、贴 key、点「保存」。
配置存在浏览器 localStorage 里，刷新不丢，随时可以点「清除」退回本地引擎。

支持两条通道：

| 通道 | 覆盖 | 说明 |
|---|---|---|
| Claude | Anthropic 官方 API | 走官方 SDK，浏览器直连可行 |
| OpenAI 兼容 | DeepSeek / 通义 / Kimi / 智谱 / Ollama / 自建网关 | `POST {baseUrl}/chat/completions`，内置一键预设 |

弹窗里有「测试连接」，会把失败原因翻成人话（key 无效 / 模型名不对 / 跨域被拦 / 限流）。

> ⚠️ **跨域是服务商侧的限制。** 不少 API（比如 OpenAI 官方）不允许浏览器直接调用，
> 填对了 key 也连不上 —— 这时得换成允许跨域的服务商，或者自己搭个代理填进 Base URL。

> ⚠️ **别用推理型模型**（deepseek-reasoner、R1、o1 之类）。它们的思考过程和答案共用
> `max_tokens`，对话一长，思考就把额度吃光，接口返回 200 但 `content` 是空的 ——
> 表现就是「前两轮正常，之后开始本地兜底」。用对话模型（deepseek-chat / qwen-plus 等）更稳。

**方式二：写 `.env.local`**（团队自己 demo 用，优先级低于界面里填的）

```bash
cp .env.example .env.local   # 然后填 VITE_LLM_API_KEY
```

配好之后，顶栏徽章会从「本地引擎」变成「真实 AI · 模型名」。

---

无论走哪条通道，**怒气值始终由前端查表计算** —— 模型只负责台词和判定，
抽风也不会把游戏搞坏。调用失败会自动降级回本地引擎，并在聊天流里插一行
「本地兜底 · 真实 AI 没接上：<原因>」—— 不打断对局，但你能一眼看出这回合是谁在说话。
完整报错在浏览器控制台（`[嘴强王者] 真实 AI 调用失败…`）。

> ⚠️ key 存在浏览器里 / 会被打进前端产物，只适合本地演示。要正式上线得换成一个后端代理。

## 玩法

**点火局（杠精房 / 谈判房）**

| | |
|---|---|
| 回合 | 最多 8 轮；回合时限在设置里选（不限时 / 15s / 30s / 60s，默认不限时），选了时限的局可点「暂停」冻结倒计时 |
| 赢 | 对方怒气值到 100 |
| 输 | 自己自爆 2 次 |
| 平 | 8 轮打完谁也没破防 |

**灭火局（情商房，装修中）**

| | |
|---|---|
| 开局 | 对方怒气值 100（正在气头上） |
| 赢 | 几轮内把怒气哄到 20 以下 |
| 输 | 说错话反弹，自爆 2 次；或 8 轮没哄好（没有平局） |

怒气增量：软肋/心结 28~34 / 有效输出 12 / 无效输出 0 / 自爆 ±12（点火加分，灭火反向）。

情绪分四档，怒气越高对方越失控：**礼貌 → 阴阳 → 上头 → 破防**。灭火局就是从「破防」一路哄回「礼貌」。
跨档的那一回合有专属反馈：日志里报幕「TA 进入「阴阳期」」，怒气条闪红、对手头像抖一下、
阶段胶囊弹跳，对手气泡底色也随阶段越染越红。

把对方说到破防时，每个人有**专属收场演出**：杠精网友连发短消息后「已开启好友验证」、
亲戚头像变灰「已退出群聊」、画饼老板甩下「你先好好想想」又撤回、砍价摊主摊位灯熄「收摊了」、
甲方「已读不回」。要是你先绷不住（自爆两次），自己的气泡会灰掉 —— 你说不出话了。

每个人设有 3 张预设话术，点一下直接发。只用预设不补刀的话，怒气会卡在 90 打平 ——
想赢还是得说点自己的话。

对线里还能**斗图**：输入框旁的表情包按钮打开贴纸盘（12 张大号 emoji 贴纸），点一下插进
输入框，可以单发、也可以随文字一起发。贴纸有固定小增量（±3~8，随模式翻方向），但全局
递减 —— 第 1 张全额、第 2 张减半、第 3 张起对方看穿套路不再理你；自爆回合贴纸救不回来。
对手也会斗图：越上头越爱发，你先发它大概率回敬一张。

## 目录

```
index.html            应用外壳
src/
  main.js             状态机 + 界面（大厅 / 选人三房分组 / 对线 / 报告）
  styles.css          樱花粉 / 宝蓝双主题配色（双皮肤四态）
  data/
    categories.js     场景分类登记表：杠精房 / 谈判房 / 情商房 + 点火/灭火模式
    personas.js       人设：分类、软肋、四阶段台词、破防台词、专属破防演出
    stickers.js       表情包登记表：12 张大号 emoji 贴纸 + 剥离/解析/本地 AI 选贴
    titles.js         赛后称号判定（点火 / 灭火两套）
    fallbacks.js      判定标签（点火 / 灭火两套）、通用兜底台词
    providers.js      服务商清单与一键预设
  lib/
    duel-engine.js    怒气值 / 情绪阶段 / 软肋判定 / 胜负（fire 点火 / extinguish 灭火）
    llm.js            大脑适配层：本地 / Claude / OpenAI 兼容，同一套返回值
    settings.js       用户填的 AI 配置，存 localStorage
    audio.js          WebAudio 现场合成音效，不加载任何音频文件
    dom.js            h() —— 所有文本走 textContent，绝不拼 HTML
  ui/
    settings-dialog.js   「接入你的 AI」弹窗
scripts/
  smoke.mjs           无头冒烟测试：引擎路径 + 灭火局反向判定 + 远程通道解析与降级
  dom-check.mjs       jsdom 里真跑一遍界面，含三房分组与设置弹窗
```

人设、软肋、台词全是数据，加一个对手只需要往 `src/data/personas.js` 里加一条（挂上 `category` 就进对应房间）。
