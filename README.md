# 杠精陪练房 · GANG.AI

> 把吵架做成一门有怒气条、有软肋、有赛后复盘的对线竞技。

**你的目标不是把道理讲赢 —— 是让对面先绷不住。**

传统对话式 AI 让你「说服」它。我们反过来：你和 AI 对线，任务是把对方聊到破防。
每个人设都藏着 2–3 个软肋，戳中了怒气值飙升；但你自己说急了也会自爆两次直接判负。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:5173
```

不用配任何 key 就能完整玩一局 —— 默认走本地引擎。

```bash
npm run build      # 产物在 dist/，纯静态，扔哪都能跑
npm run smoke      # 不开浏览器，验证引擎的四条路径
npm run dom-check  # 用 jsdom 真跑一遍 UI：选人 → 对线 → 打完 → 报告
```

## 接真实 AI（可选）

```bash
cp .env.example .env.local   # 然后填 VITE_LLM_API_KEY
```

填了 key 之后，顶栏的徽章会从「本地引擎」变成「真实 AI · 模型名」。
模型负责自由发挥台词，但**怒气值始终由前端查表计算** —— 模型抽风也不会把游戏搞坏，
调用失败会自动静默降级回本地引擎，玩家看不到报错。

> ⚠️ Vite 会把 key 打进前端产物，只适合本地演示。要正式上线得换成一个后端代理。

## 玩法

| | |
|---|---|
| 回合 | 每回合 30 秒，最多 8 轮 |
| 赢 | 对方怒气值到 100 |
| 输 | 自己自爆 2 次 |
| 平 | 8 轮打完谁也没破防 |

怒气增量：软肋 +28~34 / 有效输出 +12 / 无效输出 0 / 自爆 −12。

情绪分四档，怒气越高对方越失控：**礼貌 → 阴阳 → 上头 → 破防**。

每个人设有 3 张预设话术，点一下直接发。只用预设不补刀的话，怒气会卡在 90 打平 ——
想赢还是得说点自己的话。

## 目录

```
index.html            应用外壳
src/
  main.js             状态机 + 四个界面（选人 / 对线 / 结局 / 报告）
  styles.css          深夜聊天窗配色
  data/
    personas.js       3 个人设：软肋、四阶段台词、破防台词
    titles.js         赛后称号判定
    fallbacks.js      判定标签、通用兜底台词
  lib/
    duel-engine.js    怒气值 / 情绪阶段 / 软肋判定 / 胜负
    llm.js            大脑适配层：本地引擎 + 真实 Claude，同一套返回值
    audio.js          WebAudio 现场合成音效，不加载任何音频文件
scripts/
  smoke.mjs           无头冒烟测试：引擎四条路径
  dom-check.mjs       jsdom 里真跑一遍界面
```

人设、软肋、台词全是数据，加一个对手只需要往 `src/data/personas.js` 里加一条。
